# P-GDN3-044: Dynamic Canonical Address Frame

## 1. Metainfo

- Status: preregistered; implementation pending strict CUDA contract
- Date: 2026-08-15
- Benchmark: directional MQAR L1024 wrong-key binding regime
- Fixed setting: D128/L2/H4/K32/V32, native FutureSeed, 10 epochs,
  batch32, seed123
- Arms: contemporaneous native GDN2 control, then one matched candidate
- Resource: one task-mode GPU, no concurrent model or evaluation process

## 2. Evidence And Hypothesis

The clean-room `GDN_decouple_k` transfer has now bounded three nearby ideas.
P031/P036 show that separate erase and write/read keys break coherent row
ownership. P042 shows that forcing native Q/K toward a midpoint destroys their
useful differential. P043 preserves raw Q/K pairing with a static
biorthogonal gauge, but balanced accuracy still falls from `.04850` to
`.01975` and its independently warmed step costs `1.9149x`. Static Q/K
coordinates are therefore closed.

The untested mechanism is a changing address frame inside the live token scan.
If wrong-key errors arise because one fixed K basis must represent all phases
of a long sequence, a bounded token-dependent frame should let the same
K32xV32 state reorganize addresses without splitting ownership or adding a
second memory. The falsifiable prediction is a large, bidirectional gain on
future and past queries, fewer total errors, and at least a `.05` reduction in
wrong-key valid-value swaps under bounded state geometry.

## 3. Mechanism

For token `t`, each layer produces a diagonal frame

`C_t = Diag(exp(l_t))`,

where `l_t` is generated by a D128->8->H4*K32 controller, centered per head
and bounded by `0.5*log(2)`. The output projection is zero initialized. Native
Q and K use one coherent factor:

`q'_t = q_t C_t`, `k'_t = k_t C_t`.

The existing KxV state is transported from the preceding token frame to the
current frame by adding the exact log-frame difference to native row decay:

`g'_t = g_t + l_t - l_{t-1}`, with `l_-1 = 0`.

The cumulative frame term telescopes exactly to `l_t`; it cannot accumulate
unbounded frame scale. The unchanged pinned-official `chunk_gdn2` performs the
only recurrent scan. At sequence end, rows are multiplied by `C_T^-1` so the
terminal state and native FutureSeed cache are in one canonical basis. The
candidate adds exactly 4,096 parameters across two layers, no persistent
state, scan, cache, second core, custom recurrence, task rule or selector.

## 4. Novel Boundary

P044 is not P031/P036 because read, write and erase retain one K owner. It is
not P042 because it preserves the full native Q/K differential rather than
contracting it. It is not P043 or P020 because the frame is token dependent
and explicitly transports the live recurrent state inside the scan. It is not
P007 state feedback because incoming state is not merely read to perturb
pre-scan projections. It changes the coordinate system of the physical state
transition while retaining one official kernel and a canonical cross-layer
FutureSeed interface.

## 5. Strict CUDA Contract

The exact pushed SHA in a clean detached worktree on the sole GPU must prove:

1. exact CUDA index0/UUID, pinned FLA and Zoology SHAs, Triton short
   convolutions, exactly two official `ChunkGDN2FunctionBackward` paths and no
   fallback;
2. exact matched parent tensors and exact zero-frame output and terminal-state
   identity for both zero and nonzero incoming recurrent state;
3. exact parameter delta 4,096, state size 4,096/layer, one scan/layer, finite
   nonzero first-stage gradients, exact parent gradients at identity, and
   finite nonzero second-stage gradients after opening the frame;
4. exact native FutureSeed producer, terminal state and transported seed at
   identity;
5. exact frame telescoping, factor range `[0.70,1.42]`, condition number at
   most `2.05`, finite output/state dependence, fixed data hashes and no
   concurrent GPU model process.

Any miss closes the implementation before training. No CPU model smoke is
allowed.

## 6. Fixed Matched Protocol

Construct one canonical native initialization, save it, run the native
control, then map the same parent tensors into the candidate and run it. Both
arms use identical source, data, optimizer, schedule, batch order, seed and
evaluation cases. The only candidate tensors are the fixed rank-8 frame
controllers. There is no repeated control, radius/rank/controller/sharing,
seed, LR, loss, batch, width, depth, duration or run-order arm.

## 7. Registered Gates

Activation requires both layers active, frame-log and frame-delta RMS at least
`1e-3`, board/token variation and controller output RMS at least `1e-4`, Q/K
relative changes and effective-decay change at least `1e-3`, exact telescoping
within `1e-5`, factor bounds, canonicalization error at most `2e-3`, finite
variable canonical terminal state and active native FutureSeed.

Quality requires every condition:

- balanced accuracy at least `.55` and at least control `+.15`;
- future and past accuracy each at least `.50` and control `+.10`;
- joint exact at least `.06` and control `+.04`;
- fewer total query errors; and
- wrong-key valid-value swap fraction at least `.05` below control.

Elapsed, post-warm wall and independently warmed-step ratios must each be below
`1.30x`; peak allocation must be below `1.12x`. Any integrity, activation,
quality or cost miss discards the complete dynamic-frame family. There is no
frame radius/rank/controller/sharing, canonicalization, seed, LR, loss, batch,
width, depth, epoch or duration rescue.

decay, factor, canonical-state and FutureSeed diagnostics, timing/memory,
