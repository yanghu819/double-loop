Mechanism conclusion

  • The first-loop mixed exact is nearly unchanged: 2.34% control versus 2.15% block memory. The pretrained backbone itself was not broadly destroyed.
  • The control improves from 2.34% to 25.20% over loops. Block memory stays around 2%, so the damage is specifically to iterative refinement.
  • The saved state is routed exactly and receives gradients. Failure is not a fallback, disconnected tensor, extra parameters, or missing supervision.
  • A terminal GDN2 state is tied to the just-processed hidden trajectory. Reusing it as the next macro-step initial state is not the same operation as FutureSeed's cross-layer directional initialization.
  • Do not sweep state blend, gate bias, or decay. The next FutureSeed2 candidate must transform information into a compatible seed or communicate across more layers without carrying raw terminal state.
