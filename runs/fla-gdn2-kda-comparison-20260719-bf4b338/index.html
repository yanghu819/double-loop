FutureSeed 换不同 Linear Attention，谁更有效？

固定数据、600 steps、D128/L6、loop4 和每个 loop 的 CE，只替换 recurrent state update。FutureSeed 仍是上一层终态注入下一层初态，不是右到左扫描。

结论：原 GDN v1 胜出；GDN2 次之；KDA 最弱。更细粒度的 memory edit 在这份预算下没有提高全局闭合，反而学得更慢。按预设规则，不把 GDN2/KDA 升到大模型；回到已证明仍有斜率的 clean data/compute scaling。

机制判断和下一步

判负的假设：hard Sudoku 的主要瓶颈不是“每个 state channel 缺少更细的 erase/write/decay 控制”。如果它是，预期顺序应为 GDN2 > KDA > GDN v1；实际是 GDN v1 > GDN2 > KDA。

保留的发现：原生 FutureSeed 能无损迁移到 GDN2 和 KDA 的矩阵状态，kernel 与梯度都正确；因此 FutureSeed 不是绑定某一个 RWKV/GDN 方程的 hack。但这轮没有 no-FS 新对照，不能把两条新 backbone 的 opening 单独归因给 FutureSeed。

决策：停止 GDN2/KDA 的 seed、LR、loss、width 补表，也不立刻上 D224。恢复 P-SCALE-034 的原 GDN v1 clean full-diversity 长训练到 step20000，因为那条曲线在 step16000 仍有真实 exact 正斜率。
