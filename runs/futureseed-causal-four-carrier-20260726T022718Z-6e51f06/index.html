FutureSeed on/off across four causal carriers

Official RWKV7/GDN/GDN2/KDA, one seed, byte-identical initialization within each pair, same data order, same optimizer, same five-loop loss, GPU1 only.

SUPPORTED: FutureSeed improves 46-50-blank full-board exact by at least 10 points on 4 causal carriers (rwkv, gdn, gdn2, kda). The cross-carrier causal gate passes.

Mechanism under test

Layer l: causal scanx1 -> x2 -> ... -> xT
Keep its terminal recurrent state hT[l].
->
Layer l+1: seeded causal scanh0[l+1] = gate * normalize(hT[l])
FS-off sets this injected state to exactly zero. No reverse scan is added.

Interpretation boundary

This is a one-seed causal mechanism gate, not a final scaling-law result. Full-board exact is the primary outcome: a lower CE or higher per-blank accuracy without more completely solved boards does not count as mechanism success. The pre-registered success rule requires a ten-point b46-50 exact gain on at least two carriers.
