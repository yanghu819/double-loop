通俗地说：loop1 只解出约 2.3%，loop5 能到 46.7%，所以 loop 不是摆设。但把 state 翻倍后，step31500 的提升没有稳定保留到 step33000。问题不是“模型完全不会反复修改”，而是“这些修改在最难题上不够稳定”。

这次实验真正回答了什么

支持：FutureSeed + loop 有真实的逐轮修正能力；新增通用 recurrent memory 也能在不破坏原函数的情况下学习。
不支持：继续把同一种 GDN state 做宽就能稳定解决更多 blank。普通 state width 不是当前可靠 scaling law。
下一决策：保留 GDN/FutureSeed/loop 主干；不扫 state 宽度、LR、seed、loss 或 noise。下一条高信息量轴必须改变数据覆盖方式或通用 state formulation，而不是在附近拧旋钮。
