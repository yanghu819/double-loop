Solid 结论与边界

数据多样性真的有用

相同模型和步数下，3.83M 独立题把总体 exact 从 20.70% 推到 25.00%，不是靠改 loss 或规则。

Loop 需要先学会表示

训练早期 loop 增益很小；数据和训练够了以后，loop3 才出现大跳。这说明 loop 是计算，前提是 backbone 已学到可迭代的状态。

最难题仍没解决

56–64 blanks 只有 12.70%。hard case 虽从 25 错降到 5 错，但还没全局收敛，下一步仍应 scale 数据 token 和通用 state capacity。

不能乱讲：这轮证明的是 full-diversity data scaling 对 FutureSeed-GDN 有效；它还没有单独证明 FutureSeed 优于 full-data no-FS，也没有完成和官方 EqR 的同预算最终对比。
