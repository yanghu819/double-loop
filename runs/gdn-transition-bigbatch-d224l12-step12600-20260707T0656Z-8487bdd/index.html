Decision

The result is not a loop failure: loop1 to loop5 still improves exact by roughly fifteen points. The failure is that every hard bucket shifted below the relevant baseline checkpoint. Larger effective batch did not stabilize hard exact; it made the operating point worse.

Next useful work should not be a batch-size table. The hard cliff needs a change in state information, data scale/curriculum, or checkpoint selection, while staying away from solver-style repair, search, selector, or task rules.
