Official EqR Maze Case Evidence

Question: on the official EqR Maze code path, what changes with and without FutureSeed?

What is solid: this uses official locuslab EqR clones, official Maze30 unique data, official checkpoints, and the same EMA loading path as evaluate.py. No local online maze sampler, no repair, no selector.
Main finding: the e256 official pair does not solve Maze paths. Token accuracy is about 0.868 for both, but path F1 on visualized official cases is about 0.001 because both models almost never emit PATH. Token accuracy alone is misleading here.
