RWKV Maze Budget Decoder: FutureSeed vs noFS

Mechanism question: can a generic learned path-budget decoder turn RWKV Maze logits into a sparse correct path, and does FutureSeed improve that ranking? The answer from this run is no: both models learn the path count, but the selected cells miss many true-path cells.
