FutureSeed: RWKV vs GDN vs GDN2 vs KDA

One seed, one data order, one training budget, one evaluator. GPU1 only; no CPU model smoke and no silent fallback.

Interpretation boundary

This benchmark compares FutureSeed-enabled recurrent carriers at one finite budget. It is not a with/without-FutureSeed ablation and it is not evidence about each architecture's asymptotic ceiling. The separate matched no-FutureSeed result supports the causal FutureSeed claim.
