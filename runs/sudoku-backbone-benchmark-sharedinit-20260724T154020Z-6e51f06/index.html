Interpretation boundary

This is a one-seed, finite-budget, matched-state and matched-recipe comparison of FutureSeed-enabled recurrent carriers. It is not a with/without-FutureSeed ablation, an architecture-specific hyperparameter study, or evidence about asymptotic ceilings. In particular, state matching uses H6 x K32 x V32 for every carrier; official GDN commonly recommends H x K = 0.75D with expand_v=2, so this run deliberately does not use GDN's native recommended geometry. The separate matched no-FutureSeed result is needed for a causal FutureSeed claim.
