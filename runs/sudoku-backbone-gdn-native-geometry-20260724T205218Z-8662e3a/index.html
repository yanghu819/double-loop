解释边界

这条实验只回答“state-matched GDN 是否因为 K/V 压缩而被冤枉”。答案是否定的：native geometry 有更大的 value state 和更多参数，但没有达到预注册的 CE 或 46-50 blank 提升，51-64 blank 仍为零。它不证明 GDN 永远不行，也不比较 FutureSeed on/off；它只关闭继续扫 GDN K/V 比例这条低收益路线。
